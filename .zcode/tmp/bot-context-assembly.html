发起一次对话：Bot 上下文装配全景（AgentScope 执行器）

每次 run，后端 executor 从数据库与各配置面装出 6 大类内容 + 1 份跨 run 状态，打包成一份 JSON 发给 AgentScope 服务，由它转成最终的模型请求。

用户发消息Web / 消息通道 / 例行任务
→
后端 executor 拼装executor.ts · 鉴权/审批/凭据全在后端
→
POST /v1/runs打包 ①–⑥ 项，NDJSON 流回事件
→
AgentScope Agentruntime.py · system_prompt + AgentState + Toolkit
→
模型 API 请求chat/completions（或各家同构协议）
标注说明： ✓ 有前端配置页 自动 · 无需配置 特殊路径
①

本轮输入 prompt

→ AgentScope 本轮 UserMsg
reply_stream() 的输入消息
任务文本用户消息 / Bot 唤醒 / 例行任务，本轮问题的本体自动
引用回复上下文被引用消息的 JSON 摘录（含截断）自动
审批续传 / 接管恢复恢复暂停 run 时重放已批准的效果与屏幕接管说明自动
当前时间 / 语音约束时间每轮注入；语音通话时加"只读不改写"约束自动
发起时插话 steeringrun 启动瞬间已排队的用户补充，合并进 prompt；运行中插话走工具桥注入自动
本轮附件图片随消息上传的图片，转 Base64 DataBlock自动
AGENTSCOPE 对应物UserMsg（本轮输入）id = 消息 ID；图片拼在 content 里；配置页：无，全部是当轮数据

→ AgentScope AgentState.context
按角色逐条重建为 User/AssistantMsg

跨 run 状态（隐性第 7 类）

不随 /v1/runs 请求传，
存在 AgentScope 服务本地
AgentState 快照每次 run 完成原子保存（版本号防并发覆盖）；恢复时剥离临时块、续补尾部历史StateStore · 自动
自身压缩 summary上下文逼近模型窗口时 AgentScope 压缩出摘要，随快照持久压缩工具 · 自动
AGENTSCOPE 对应物StateStore（本地 JSON 快照）"长对话记忆"的另一半；与 PG 全量聊天记录分离

最终发给模型的请求

以 OpenAI 兼容为例，其余供应商由对应 ChatModel 同构转换
POST {模型 baseUrl}/chat/completions

{
  "model": "…",
  "messages": [
    { "role": "system",
      "content": "You are an assistant in MyPal. " + ② 全部 instructions },
    // ↓ 仅当 AgentScope 自身压缩触发过（随快照恢复）
    { "role": "user", "content": "自身压缩 summary" },
    // ↓ ③ 后端压缩摘要（游标前内容的唯一记录）
    { "role": "user", "name": "workpal_compacted_context", … },
    { "role": "user", "name": "workpal_recalled_memory", … },
    { "role": "user", "content": "历史消息…" },      // ③ 窗口 50/200 条
    { "role": "assistant", "content": "历史回复…" },
    { "role": "user", "content": ["本轮 prompt", 图片…],
      "name": "user" }                        // ① 本轮输入
  ],
  "tools": [ { "type": "function",
      "function": { "name", "description", "parameters" } } … ],
  "stream": true,
  "max_completion_tokens": …,
  "reasoning_effort": "…",
  "parallel_tool_calls": false
}
工具不直连外部。模型只会"发起调用"，真正执行经工具桥回到 TS 后端：鉴权、审批暂停、密钥注入、幂等都在应用后端完成。
响应是流。模型输出 → AgentScope 服务 → NDJSON 事件流 → 后端 → 前端增量渲染；usage 每轮回传统计。
每一轮都会重算。除 AgentScope 快照外，①–⑥ 每次 run 重新装配；改了 Bot 指令 / 技能 / 连接，下一轮立即生效。
数量盘点。6 大类 + 1 份状态；7 项有前端配置页，其余自动装配。
装配链路：packages/adapters/src/executor.ts（拼装与鉴权）→ agentscope-runtime.ts（打包 + 工具桥）→ services/agentscope/src/workpal_agentscope/runtime.py（Agent 构造）→ 模型 API。压缩摘要跨 run 注入行为已修复并通过 services/agentscope 全量测试。
