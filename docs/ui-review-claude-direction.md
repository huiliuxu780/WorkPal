# UI 评审报告与 Claude 风格落地方向（2026-10-06）

> 方法：oil-ui-pro 评审协议。主代理取证（截图工具 shoot.mjs，1280x900 桌面 + 390x844 手机，界面语言 zh-CN），
> 两个**独立盲审子代理**按 reviewer-manual【全新界面与改版评审】标准分别打分（未给源码、未给主代理观点）。

## 0. 结论

**基线分：4 / 10（两位盲审独立给出同分）。**
一句话诊断：这是一套**纪律尚可但设计声音为零的 shadcn 默认审美**——对齐与 hairline 基本合格、文案质量不差，
但品牌锚点缺失、冷灰底 + 纯黑按钮的无品牌配色、控件尺度三套并存、零消息态未设计、暗色未校准、弹层尺寸与内容脱钩。
骨架（信息架构、组件分层、i18n 机制）可留；**皮肤与控件语言几乎全要重做**。这与“改成 Claude 风格”的目标不冲突：
Claude 方向恰好要求暖纸底、单一赤陶强调、衬线标题声音和被设计过的空态，等于把上述缺陷逐项反转。

## 2. 问题清单（两位盲审收敛后的合并版）

### 2.1 品牌与主构图
- 全产品**无 wordmark / 品牌锚点**：侧栏顶部只有三个裸图标；注册页 logo 是全页对比度最低的元素（浅灰圆坐浅灰底），第一印象页把品牌做成最弱的东西。
- 品牌符号几何不统一：注册页“灰圆+两竖杠”、Bot 头像“赤陶圆+两点”、头像设置“粉圆+两竖杠”，三处两种几何。
- **零消息态未设计**：任何被清空的线程只剩一块死白（01/04/09）。首跑有问候卡，但“清空后/播种后”的常驻空态不存在；移动端同样没有专属空态。
- composer 是唯一主角却做得最弱：910px 通栏、白底浮在同色温画布上像幽灵、禁用发送箭头对比接近消失且无解释。
- 侧栏中段约 600px 真空（只有一条会话时）；“新对话”最高频动作被压成一个无文案的“+”。

### 2.2 色彩与暗色
- 浅色是冷 zinc 灰绿（画布约 #f0f0ee），与暖纸方向背道而驰；全页零暖色零品牌色（注册/引导页）。
- **四个色相各自为政**：赤陶（头像）、品红（头像风格选项图标）、纯黑（CTA）、红（清空对话）——没有强调色纪律。
- 暗色未校准：输入框边框对卡底约 1.3:1，三个密码框在暗色里几乎隐形；segmented 灰轨在暗色消失、选中 pill 读不出；禁用态语言随主题翻转（浅色灰底白字 / 暗色灰底深字）。
- **焦点环是浏览器默认蓝、直角、full-bleed 贴边**（04 左下用户行），同时违反强调色、圆角体系与焦点环形态三件事，读作渲染 bug。

### 2.3 控件语法（一套语法三种方言）
- 控件高度三套：注册页输入约 46px、引导页约 31-34px、设置弹层约 30px；主按钮尺寸三套（456px 满宽黑 / 48x28 灰药丸 / 48x28 黑药丸）。
- **禁用主按钮灰脸且不给原因**（引导“继续”、设置“修改密码”、新建“创建”），灰脸读作“坏了”。
- 圆角实际四套（直角焦点环 / 约 12px 卡 / 约 16-24px 弹层 / 全圆 pill），而 ui-tokens 宣称单一 0.75rem。
- segmented 尺寸与内容失配（外观三词占 616px 宽轨）；textarea 保留浏览器默认 resize 斜纹把手。

### 2.4 线框病与弹层尺寸
- 设置弹层“每个层级都画线框”：四个区块各套边框卡、卡内输入再套边框、segmented 再套灰轨；留白与小标题本已完成分组。
- 弹层固定大尺寸与内容脱钩：集成弹层约 500px 真空、制品/用量弹层同病；空状态还摆着“空货架+收银台”（未配置 catalog 却给搜索框）。
- 可滚动内容无 affordance：设置弹层底部卡片被硬切，无渐隐/滚动条/阴影提示。

### 2.5 文案、术语与 i18n（真实缺陷）
- **中文界面残留未翻译英文**：集成弹层 “Browse MCP servers” 按钮 + “Configure a plugin catalog on the server to connect apps.”；制品页标题 “Artifacts”、“Filters”、“No artifacts found.”。与 10 语言承诺直接冲突。
- 同字段 helper 跨面板不一致且近义：新建面板“标题”placeholder=“描述这个 Bot 做什么”、“描述”=“这个 Bot 是做什么的”；设置面板同字段又换一套示例文案。
- 术语分裂：Bot / 机器人 混用。
- 侧栏左下用户行出现字面文本“文字”（疑图标回退/aria 泄漏成可见文字），05/06 复现。
- “已有账户？ 登录”全角问号后再加空格，双倍断距。
- 危险操作语义缺失：“清空对话”是裸红字文本链接，挂在“导出”标题下、无按钮边界无确认暗示。

### 2.6 可访问性与反馈（含一条可复现控制台错误）
- **Base UI `nativeButton` 警告**：设置弹层打开即触发（控制台可复现）——某交互件向期望原生 `<button>` 的触发器传了非原生元素，键盘/读屏语义可能整组失效。与视觉改版无关，应独立先修。
- 12px 灰 label 压灰底/黑底均偏吃力；暗色输入 affordance 消失（见 2.2）；三处禁用钮不给原因（认知与读屏用户同受损）。
- 可见反馈缺口：无 skeleton/流式指示证据、折叠区无信息摘要、禁用发送无 tooltip、segmented/开关选中过渡无证据。

### 2.7 移动端
- 390x844 是桌面布局压进手机：顶栏四元素一字排开、桌面沙箱入口在手机上零交代、composer 照搬桌面结构、无移动端空态与字阶调整，读作“坏掉的桌面页”。

## 4. Claude 风格落地方向（收敛后的 5 个工作包）

1. **换底**：ui-tokens 33 语义槽整体重映射——浅色画布暖纸（约 #FAF9F5 / 侧栏深一档 #EEEAE2、hairline #E8E4DA），暗色暖炭（约 #16130F 底 / #1E1A15 面）恢复两档表面层级；同步修暗色三病（输入边框提对比、segmented 恢复可见轨、禁用态跨主题统一）。验收：100%/200% 目检暗色输入框与选中 pill。
2. **立唯一强调色赤陶（约 #C96442，hover #B4552E）**：接管主按钮、segmented 选中、active 导航、开关 on、焦点环、链接与启用态发送；退役纯黑 CTA 与品红图标；红色只留破坏性操作并升级为按钮+二次确认（顺手解决“清空对话”挂错父级）。验收：全界面只剩“暖中性 + 赤陶 + 语义红”。
3. **统一控件尺度与主操作语言**：输入/select 40px、textarea min 96px、主按钮 40px 高且**永不灰脸**（禁用=降不透明度+按钮下一行原因文案，三处全加）；消灭 48x28 小药丸与 616px 巨型 segmented；圆角收进 token 梯度；同轮把 segmented/开关/关闭钮换原生 `<button>` 销掉 Base UI 警告。
4. **字体双轨 + 品牌锚点 + 空态主角**：页面/弹层标题与空态问候换衬线 display（CJK 走 Noto Serif SC 600，28-32px），正文保留 Geist+PingFang；侧栏左上补 wordmark；任何零消息线程居中给衬线问候 + 2-3 枚建议 chips（三端统一）；侧栏真空区换带文案的“新对话”主按钮。验收：中文多行标题在 100%/200% 不裁切不孤字。
5. **弹层信息重设计 + i18n 清零**：弹层改内容自适应高度消灭真空；未配置 catalog 时收起搜索框；翻译全部残留英文串；去设置四卡边框改留白+小标题；弹层加上下渐隐；引导页改居中卡+步骤指示+品牌 mark；修“文字”泄漏与 textarea 把手；统一 Bot 术语与同字段 helper 文案。验收：10 语言包扫描零未翻译。

移动端单独成包（第 6 包）：移动专属空态、composer 减法、桌面沙箱入口的可达性交代、安全区收边。
