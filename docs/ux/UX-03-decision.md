## 0. 三条核心规则（写死，任何实现都不能违反）

1. **聊天头部不再承载管理功能。** 模型切换器、Agent 电脑按钮、名称行从头部移除；头部位置不保留替代表头。管理项的唯一入口是侧设置面板。
2. **悬浮头像是身份与状态的唯一常驻表达。** 水平居中贴顶浮于对话栏；单击开侧面板、再单击收起；运行中/待审批状态以环色+文案表达在同一个悬浮件上（不与状态 pill 分离）。它不遮挡输入、不随转录滚动消失。
3. **面板功能不丢一项。** 三 tab（详情/资料库/电脑）必须容纳现有 BotSettings 与 computer panel 的全部能力，含 CAP-01 权限区；例行任务列表进详情 tab，完整编辑仍钻入 RoutineEditor。

## 2. 面板内容映射

- **详情**：例行任务（列表+开关）、名称/头衔/描述、通知、权限（CAP-01 区原样）、模型+思考、其余高级项（记忆范围/朗读/音色）、导出/清空。
- **资料库**：技能（KnowledgeSection）+ 草稿板（ScratchpadSection）。
- **电脑**：ComputerModePicker + 实时屏幕 + 维护动作 + 打开完整窗口；面板头部齿轮 settings↔computer 互切保留。
- 面板头部仅保留导出/关闭两圆钮（参考截图）。

## 3. 头部元素去向

| 原头部元素 | 去向 |

| Agent 电脑按钮 | 电脑 tab |
| run 状态 pill | 合并进悬浮头像（Q4） |

## 5. 风险与对策

- 悬浮件遮挡首屏消息：贴顶 + 转录 `padding-top` 预留；窄屏（<md）收为纯球隐藏名称。
- 状态可读性：环色之外保留文案（运行中 · N 项动作 / 待审批 · 事由），不只靠颜色。
- 群簇成员过多：露前 3 球 + 计数，其余进群设置。
