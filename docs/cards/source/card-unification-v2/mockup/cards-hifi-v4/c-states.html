Run 已结束

pending 输入请求仍可回答；保留来源、权限与 expiry。

外部结果未知

运行已停止，发送结果未确认。没有“已作废”，也没有重新执行按钮。

活动事件边界

agent.tool.completed 只表示执行活动；付款、发信、安装与 Routine 以业务事实为准。

C4 · 键盘与无障碍 文字、图标或形状和颜色共同表达状态

可聚焦示例

Tab 到此按钮后按 Enter 才触发；页面没有全局发送或批准监听。

减少动态效果

遵循 prefers-reduced-motion；焦点使用 :focus-visible 外描边。所有状态都有文本，失败使用方形/叹号，过期使用空心环。

按键/能力作用域行为
Tab / Shift+Tab页面与对话框按 DOM 顺序浏览控件；原生 dialog 约束焦点。
Enter / Space当前聚焦控件只触发该控件；没有全局 consequential 快捷键。
Esc最上层关闭 dialog、面板或 queue；不等于拒绝或取消。
焦点恢复关闭后返回触发入口；来源 Interaction 可被聚焦。
状态播报aria-live="polite"revision、queue、安装与重新加载结果可被读出。
