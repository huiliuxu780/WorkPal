原型操作提示

使用 Tab 浏览控件，Enter/Space 只触发当前聚焦按钮，Esc 关闭最上层。A10 在详情页操作；A12 与 B3 在卡片总览操作；N1 在提醒页操作；读取失败“重新加载”在状态页操作。所有业务状态变化均为本地确定性演示。
