CARD-01D P2 red-first evidence — attention queue response race (web)
===================================================================
Finding: PR #147 review comment 4390254763 — out-of-order responses could
         resurrect an already settled request: a slow response started before a
         newer one overwrote the queue state and re-notified the settled item.
Regression case (added in apps/web/src/pages/AttentionQueue.test.tsx):
  - "drops a superseded response so a settled request cannot resurrect"
    Two loads race: the poll started at refreshToken=0 is still in flight when
    Shell bumps refreshToken=1 after the local decision. The newer request
    resolves first with an empty page; the superseded response then resolves
    with the old pending item.
