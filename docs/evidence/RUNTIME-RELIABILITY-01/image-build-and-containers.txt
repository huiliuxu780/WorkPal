## the corepack defect, and the proof the fix is baked into the final image
# 'corepack enable' installs only a shim, and 'corepack prepare' caches under the
# invoking user's home. The build stage runs as root and /root is 0700, so a
# prepare without COREPACK_HOME is invisible to USER node and pnpm is downloaded
# at container start. The fix pins COREPACK_HOME=/opt/corepack and chmods it a+rX.
# Proof: no network, no prepare step, pnpm resolves from the image alone.
$ docker run --rm --network=none --entrypoint pnpm workpal-rr01:app3 --version
9.15.0
user=node COREPACK_HOME=/opt/corepack contents=lastKnownGood.json v1
