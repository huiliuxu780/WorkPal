## Where progress is recorded

Every row uses exactly one status: `not-started` (no implementation begun), `in-progress` (implementation or verification underway), `done` (completion evidence linked), or `blocked` (the reason and needed decision/external change linked). A design review or code audit alone does not change `not-started`. When work starts or completes, update its status here and add the branch/PR link, actual tests, and changed decisions to the relevant implementation note.
