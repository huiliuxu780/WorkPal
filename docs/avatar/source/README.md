# Pinned avatar source assets

This directory contains byte-for-byte copies of the supplied implementation SVGs: four full characters, four compact 16px characters, and the prop SVGs, plus the eye-bound reference. Verify them with SHA256SUMS. They are review inputs, not yet production assets.

The compiled avatar spec and MOTION-SPEC v0.6 FINAL are pinned by SHA-256 in [AV-00-decision.md](../AV-00-decision.md). They are not copied into the repository because their originals include local identity/path details prohibited by project policy. Do not edit the originals or silently alter the SVG paths.

The supplied compact dot and treble SVGs are identical. A newly frozen 16px design revision is required before this set can satisfy four visually distinct characters at 16px.
