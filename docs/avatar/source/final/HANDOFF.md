## 4. 各状态时间和关键帧速查（R = 各角色 R′）

| 状态 | 出场 / 开场 | 循环 | 静帧 |
|---|---|---|---|
| 待机 | — | 呼吸 3.6s（sy ≤1.035）；眨眼 2.5–6s 一次、160ms；符号轻晃 ±4° / 2.6s；张望 3–7s 一次、1.4s；小蹦 6–14s 一次（0.08R，带阴影）；招牌动作 9–18s 一次 | 睁眼 |
| 工作中 | 3 次 × 420ms 弹跳（↑0.18R，带阴影）+ 笔记本 0→1.12→1（320ms） | 每 600ms 点头（0.03R、180ms，符号晚 80ms）；绿光 0.25→0.60；光标 1s 闪；30s 无进展放慢到 1.2s；pulse 间隔 ≥2s | 笔记本、绿光 0.4、看屏幕 |
| 等审批 | 黄牌 0→1.12→1（320ms），瞳孔 200ms 看黄牌 | 黄牌浮动 ±0.05R / 1.6s；3s 后首次招手，之后 ≥30s 一次，最多 3 次；每次 900ms（挥 ±14°×3、身体歪 3°、小跳 0.08R） | 黄牌 + 看黄牌 |
| 等你回答 | 问号弹出 320ms，瞳孔往上 | 每 4s 换边歪头 ±4°（500ms）；问号跟着倾斜 8°；2.6–3.2s 间快速看另一侧 | 问号 + 往上看 |
| 出错 | 0–150 吓一跳（↑0.12R、sy 1.08 / sx 0.93、眼 1.10、符号 +0.05R、阴影）→ 150–300 落回 → 300–400 叉眼出现 → 300–940 摇头（−6° / +4.5° / −2.5° / +1° / 0，位移 −0.06 / +0.045 / −0.025 / +0.01 / 0 R，于 400 / 560 / 720 / 860 / 940ms）→ 940–1240 泄气（↓0.06R、sy 0.95 / sx 1.03、符号 ↓0.04R 转 8°） | 不循环，停住 | 叉眼 + 下沉 + 符号耷拉 |

通用：切换 ≤520ms（旧道具 160ms 收、瞳孔 200ms 移）；离开出错时叉眼 120ms 收回；同屏最多 3 个动画（审批 > 等你 > 工作中 > 出错 > 待机）。精确的缓动、滞后公式见 MOTION-SPEC §3.5。

## 6. 已知问题和注意事项
1. **24px 叉眼线宽是 2.2 倍**（0.154R）。原线宽在 24px 下看不出是 ×；加粗后 1× 能看出眼睛变了，2× 屏幕能看清 ×。24px 的「失败」主要还是靠红色徽标或状态点。
2. **侧边栏不画笔记本**：会和右下角状态徽标撞在一起，运行中靠徽标表示。黄牌、问号在同一个位置，本版按同一个理由也不在侧边栏画（2026-10-19 徐哥确认）。侧边栏也不显示状态文字。
3. **波浪的笔记本是 0.85×**，其余 1.0×。
4. **容器不裁切**：动作会超出 100×100 画布（吓一跳头顶最多超出约 10 单位，摇头横向约 12 单位）；侧边栏网格格子上边距必须保持 8px，一次性动作在网格里 sy ≤1.12。
5. **发布时补的两条（2026-10-19 徐哥确认）**：黄牌 / 问号加白描边（不加的话蓝问号压在蓝 Bot 上看不见）；Bot 颜色分配规则（挑用得最少的颜色，见 SPEC §2）。
6. **状态色已合并（2026-10-19 徐哥确认）**：UX 2026-10-18 定了一套浅色 / 深色语义色（`WorkPal-agent-avatar-ux.md` §16、验收第 23 条），16px 状态点和侧边栏徽标共用，已写进 SPEC §4 / §7、`palette.json` 和演示页。剩下的风险：等你回答 `#3F8FDF` 在蓝 Bot `#4184f4` 上、等审批 `#d97706` 在橙 Bot `#e8983a` 上，徽标颜色和身体几乎一样（对比度 1.06 / 1.36，色差 ΔE 约 21 / 15），**只能靠背景色描边认出徽标**，所以同色相组合的描边加粗到 2.5px（16px 点 2px）；深色主题下这两对好一些（1.71 / 1.47）。见 `review-status-colors.png`。深色主题的符号颜色 `#1a1a1a` 一并确认。
7. 演示页的缓动是三次多项式近似，和 MOTION-SPEC 的 cubic-bezier 有细微差别；演示页不实现同屏 3 个名额和多头像错开。以规范为准。
8. 状态插画（SPEC §6）的 working 定稿图还是有脚黑色版，需要重出。
9. 上一级目录的 `/workspace/WorkPal-avatar-visual/SPEC.md`（v1）不在 `final/` 里，合入时没有动它；以 `final/SPEC.md`（v2）为准。
